## Common CSV Errors and How to Fix Them

Crypto exchanges often export CSV files with errors that prevent import into tax software. Here's how to identify and fix them.

### 1. Missing Dates

**Problem**: Some rows have blank date fields

```csv
Date,Amount,Type
2025-01-01,0.5,Buy
,1.2,Sell  ← Missing date
```

**Solution**: TaxFormatter automatically detects missing dates and either fills them from context or flags them for review.

### 2. Inconsistent Date Formats

**Problem**: Mixed date formats in the same file

```csv
01/15/2025  ← MM/DD/YYYY
2025-01-16  ← ISO format
15-Jan-25   ← Custom format
```

**Solution**: Our AI engine recognizes 20+ date formats and standardizes them automatically.

### 3. Missing Transaction Types

**Problem**: Exchange doesn't specify buy/sell/trade

```csv
Date,Amount,Currency
2025-01-01,0.5,BTC
2025-01-02,-0.3,BTC  ← Is this a sell or transfer?
```

**Solution**: We infer transaction types from amount signs and historical patterns.

### 4. Duplicate Transactions

**Problem**: Same transaction appears multiple times

This happens when:
- Downloading monthly reports that overlap
- Partial refunds create duplicate entries
- Exchange API glitches

**Solution**: TaxFormatter detects duplicates by matching timestamp, amount, and currency within a 1-second window.

### 5. Special Characters in Headers

**Problem**: Non-ASCII characters in column names

```csv
Dáte,Ámount,Çurrency  ← Non-standard characters
```

**Solution**: We normalize all headers to ASCII equivalents.

### 6. Extra Columns

**Problem**: CSVs contain internal exchange IDs, metadata, or notes

```csv
Date,Amount,InternalID,Notes,Status,ProcessingFee
```

**Solution**: Our parser extracts only the columns needed for tax reporting and discards the rest.

### 7. Inconsistent Decimal Separators

**Problem**: European vs US decimal formats

```csv
1.234,56  ← European (comma as decimal)
1,234.56  ← US (comma as thousands)
```

**Solution**: Context-aware detection determines which format is being used.

### 8. Missing Exchange Information

**Problem**: CSV doesn't specify which exchange it's from

Tax software needs to know the source exchange for accurate reporting.

**Solution**: TaxFormatter's AI fingerprints the CSV structure to identify the source exchange automatically.

### Best Practices

✅ **Download directly from exchange** - Don't edit in Excel first

✅ **Include all transactions** - Even failed or cancelled ones

✅ **Keep original files** - Save a backup before processing

✅ **Verify totals** - Check that transaction counts match
